# Gamble Tan

Personal open-source project homepage: https://gambletan.github.io/

A responsive, dependency-free static site. Project links and descriptions come from public repositories on [@gambletan](https://github.com/gambletan). No analytics, trackers, or third-party font requests.

## Preview

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Edit `index.html` for content and `style.css` for styling.

## Publishing

GitHub Pages serves the root of the `main` branch. Push updates to `main`; GitHub rebuilds the site automatically. `.nojekyll` keeps the site as plain static files.
